## 🧠 Project Prompt

Build a premium, stunning, award-winning barber website with the following structure and requirements.

Brandname Ironfade

The website starts with a top bar above the main navigation for essential information such as hours or contact details. Below it, the main navbar places the logo on the left and a small number of clean, minimal navigation links with a CTA on the right. Keep the navigation simple and uncluttered.

The Hero section is fully center-aligned in both layout and text. At the top is a visually styled section label with a subtle animated or decorative effect. Below the label is a strong main title, and directly beneath it are two CTA buttons. There is no description text in the hero. A scroll-down indicator appears at the bottom. The hero section uses generous vertical spacing with 12rem padding on the top and bottom.

The About Us section features an image on the left with a refined, premium outline or frame effect. On the right side, place the about content with headings, body text, and a CTA button. No stats are included in this section.

The Services section displays three services per row. Each service card places the service icon at the top, followed by the service title and a short description. The card design should feel modern, layered, and visually engaging rather than flat. Below the services grid, include a CTA Video section that uses a full-width background image. This CTA contains only a centered video play icon, styled prominently, with no text inside the section.

The Pricing section presents three pricing packages in a single row on desktop. Each pricing card includes a package label, a large price with currency and duration, and a short one-line explanation. A list of included services appears below using Bootstrap Icons for checkmarks. One package is highlighted as “Most Popular” with a subtle accent-colored treatment. Each card ends with a clear CTA button. Cards lift slightly on hover with smooth transitions while maintaining a clean, premium look.

The Gallery section displays four images per row. Each image includes an accent-colored overlay with a preview icon that appears on hover. Use Fancybox for image previews.

The Features section uses a visually striking split layout. An image appears on the left, and the features content appears on the right. Each feature item includes a checkmark icon and a bold, short feature heading only, with no description text. Apply creative visual treatments such as staggered layouts, subtle motion, decorative lines, or accent highlights to make the section feel modern and unique while remaining clean.

The Reviews section uses a marquee-style animation. The first row of review cards scrolls from left to right, and the second row scrolls from right to left. Add subtle dark or light gradient overlays on the left and right edges of the section, depending on the theme, to focus attention on the moving cards. Each review card shows the reviewer’s image on the left with a thick accent-colored border and a verification badge. To the right, display the reviewer’s name and location. Below that is the review text, not italic and not underlined. At the bottom, show a 4.5 out of 5 rating using star icons, and on the right side include the review platform icon, such as Google, inside an icon box.

The Team section displays four barbers per row. Social media icons appear smoothly on hover.

The Schedule Appointment section contains only a clean, minimal appointment form. All other supporting or informational content is removed to keep the focus on conversion.

The Blog section shows three posts per row, designed as magazine-style cards. Each card has a visual element at the top in grayscale that transitions to full color on hover, with a centered arrow icon appearing through a smooth fade and scale effect. The main content container overlaps the image slightly at 90% width and is centered. Display two metadata values separated by a divider, followed by the post title. About 40px below the title, include a horizontal divider and then a short two- to three-line excerpt. On hover, the card subtly elevates with smooth transitions. Blog cards must have no background and maintain a consistent, premium layout.

The Instagram section displays images in a clean grid or horizontal layout without marquee animation and without any Instagram handle label. Focus purely on visuals with subtle hover effects.

The Footer is modern, clean, and minimal, containing business timing information and essential links.

All section introductions must not include description text. Each section uses a strong title and a visually styled section label with a cool effect such as accent lines, motion, typographic styling, or decorative elements to reinforce hierarchy and branding.

## 🔄 Changes Applied

The top bar was redesigned to look more polished and visually appealing. The left side contains social media icons with a clear “Follow Us” label, while the right side displays contact information such as an email address and phone number. Clear vertical spacing was added so the main navbar does not touch the top bar. On smaller screen sizes, social icons are also displayed inside the navbar.

The hero content is fully centered and constrained to a maximum width of 800px using margin auto. The hero title uses four words instead of three, and the scroll-down indicator was redesigned to feel more premium and aligned with the brand.

In the CTA video section, the button is white by default and transitions to a dark color on hover. The section uses a background image and contains only the video play icon, with no text content.

The same outline or frame style used in the About Us image was applied to the Features section image for visual consistency.

The team card design was updated so the image appears on top with content below. On hover, social icons appear in the top-right corner, and the image smoothly zooms and overflows beyond its wrapper.

The appointment section was simplified to include only a clean, minimal form aligned to the right side, with all background overlays removed.

In the blog section, icons were removed only from the metadata area while keeping date and category text intact.

## ⚙️ Technical Rules & Stack

- Pure HTML, CSS, and JavaScript (no frameworks)
- Single HTML file (HTML + CSS + JS combined)
- BEM naming conventions
- Bootstrap-style custom container system
- CSS variables stored in `:root`
- Bootstrap Icons only
- AOS fade-up animations only
- Fancybox for gallery previews
- Custom 5px scrollbar (square edges)
- Custom mouse cursor with smooth trailing effect
- SVG favicon
- W3C-valid HTML
